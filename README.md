# Gevix

Marketing site for Gevix, a design and engineering studio. Four static pages, no build step.

- `index.html` – home
- `work.html` – case studies (`/work`)
- `blog.html` – writing (`/blog`)
- `blog/<slug>.html` – one page per article (`/blog/week-five`), generated by `build.py` from `posts.json`
- `post.html` – legacy redirect from the old `/post#slug` links

## Run locally

```bash
npx serve .
```

## Deploy

Static site on Vercel. `vercel.json` turns on clean URLs so `/work` serves `work.html`, redirects `www` and the vercel.app host to `gevix.in`, and sets security headers.

## Editing articles

Edit `posts.json`, then run `python3 build.py` to regenerate `blog/*.html` and `sitemap.xml`. Commit the output.

## Before going live

- Client names, testimonials, case-study figures, author names and "since 2019" are placeholders — replace with real ones.
- Articles are ~200 words each; expand the ones that should rank.
- Verify the site in Google Search Console and Bing Webmaster Tools (submit `sitemap.xml`).
